# results/ — small result tables of the revision (as saved for the manuscript)

Committed copies (each < 1 MB) of the summary tables that the figure scripts read, plus the headline
tables of each new analysis. `run_revision.sh figure_inputs` copies them to `$WORK/figure_inputs/` and
then overwrites them with any table recomputed in `$WORK`, so the figures always use fresh results when
available. Tables produced by the archived prior-session cells (`archive_prior_session/`) cannot be
regenerated by a refactored script in this PR; their committed copies are the reference.

Not committed (too large; regenerated by the steps): `splice_site_phylop.tsv` (4.3 MB),
`A4_gene_expression_tau.csv` (1.5 MB), `selection_site_counts_v3.csv` (11 MB), the A2 event tables
(31–47 MB) and the per-exon GC table (18 MB).
